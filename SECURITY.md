# Security

Please **don't** open a public issue for security problems. Report them privately via GitHub's **[Report a vulnerability](https://github.com/witchspace-game/witchspace/security/advisories/new)** button on the repository's Security tab. If you can't use GitHub, email **[security@witchspace.org.uk](mailto:security@witchspace.org.uk)** instead. We'll reply as soon as we can.

This matters more once multiplayer and accounts arrive (cheating, account takeover, server abuse). Thank you for helping keep commanders safe.
