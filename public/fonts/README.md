# The site's fonts

Inter, Inter Tight, Source Serif 4, Space Grotesk, Rajdhani and Press Start 2P, the Latin characters of each, from Google Fonts. All are under the [SIL Open Font License 1.1](https://openfontlicense.org/). Served from our own domain so no visitor's browser asks a third party for them (`src/site/fonts.css` for the website, `game.css` for the game).
